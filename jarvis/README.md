# J.A.R.V.I.S. — shaxsiy ovozli yordamchi (PWA)

Ishga tushirish (build kerak emas):

    cd jarvis && python3 -m http.server 8080

Telefon Chrome'da oching (HTTPS yoki localhost kerak; GitHub Pages / Netlify'ga joylash mumkin),
so'ng menyudan "Bosh ekranga qo'shish".

Imkoniyatlar: qo'ng'iroq, SMS, WhatsApp, Telegram, email, YouTube/Spotify/Google/xarita/yo'l,
budilnik (Android), taymer, eslatma, chiroq, batareya, joylashuv, eslatmalar daftari.
Ovozli buyruq (uz/ru/en), chaqiruv so'zi "jarvis" bilan qo'lsiz rejim.
Sozlamalarda Claude API kalitini kiritsangiz, har qanday jumlani tushunadi va amallarni o'zi tanlaydi.

Cheklov: brauzer ilovasi telefonni to'liq boshqara olmaydi (ekran yopiqda tinglamaydi,
boshqa ilovalarni o'zi bosa olmaydi). To'liq nazorat uchun native Android ilova
(Accessibility Service) yoki Tasker kerak.
