# Bilyard Ishlab Chiqarish — statik sayt

Oddiy HTML/CSS/JS sayt, build kerak emas.
`css/enhance.css` — dizaynni kuchaytirish qatlami (`css/style.css` ustidan ishlaydi).
Eski ko'rinishga qaytish: `index.html` dan `enhance.css` qatorini o'chiring.

## Cloudflare Pages'ga ulash
1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → shu repozitoriyni tanlang.
2. Branch: asosiy branch. Build command: bo'sh qoldiring. Build output directory: `biliard`.
3. Save and Deploy. Har push'da sayt avtomatik yangilanadi.
